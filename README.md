# NCKU Return OS｜學分地圖

這是一個本地可執行的個人復學規劃工具，用來整理畢業進度、學分缺口、必修缺口、候選課程、GPA 高風險課與畢業卡關課。

目前預設資料依據「水利及海洋工程學系學士班畢業學分檢核表【114 學年度入學生適用】」整理：

- 核心必修：28 學分
- 專業必修：71 學分
- 設計必修：4 學分，4 門中任選 2 門
- 必選修：1 學分，水利及海洋工程概論
- 選修：31 學分，其中本系選修至少 10 學分
- 預設畢業總學分：135 學分

並已先併入目前提供的抵免 / 承認紀錄：

- 113-1：體育（一）、大學國文（一）、應用物理與實驗、性別與社會、哲學概論。
- 113-2：體育（二）、大學國文（二）、法學緒論、運動與健康、應用化學與實驗。
- 114-1：體育（三）、微積分（一）、海洋物理學、工程數學（一）。
- 目前預設已完成學分：24 學分。

也已併入 115 學年度第 1 學期水利系課表資訊，供復學排課參考：

- 115-1 可優先處理：普通物理學（一）、普通物理學實驗（一）、工程圖學、水利及海洋工程概論、工程地質學、水資源工程（一）。
- 115-1 有開但受先修限制：流體力學（一）、流體力學實驗、材料力學、明渠水力學、波浪力學。
- 115-1 有開但偏畢業前階段：專題研究（二）、海洋工程設計、防洪排水工程設計。
- 115-1 衝堂矩陣已先整理：普物一 vs 工程地質學、普物實驗一 vs 水資源工程一、工程圖學 vs 防洪排水工程設計、水利及海洋工程概論 vs 工程地質學 / 海洋工程設計。

## 如何開啟

直接用瀏覽器開啟 `index.html` 即可使用，不需要網路、後端、資料庫或安裝套件。

```text
ncku-credit-map/
├── index.html
├── style.css
├── app.js
├── credit-map.test.mjs
└── README.md
```

## 功能列表

- 設定畢業總學分、水利必修、通識、自由選修、跨域課程需求。
- 查看已完成學分、尚缺學分、分類已完成學分、高風險課數量與卡關課數量。
- 新增、編輯、刪除課程。
- 依類別、狀態、GPA 風險、是否必修、是否卡畢業篩選。
- 快速查看未修必修、高風險課、9 月候選課、卡畢業課程。
- 自動產生缺口分析，包含總缺口摘要、分類學分進度列與待處理行動清單。
- 顯示建議修課時間、115-1 可修狀態、先修限制、上課時間與復學優先順序。
- 使用「決策狀態」追蹤每門課現在該怎麼處理：已完成、115-1 優先、115-1 備選、115-2 預備、先修未滿、畢業前處理、待問系辦。
- 主清單加入開課節奏、延後風險、暑假預習優先度、衝堂對象、是否放入正式課表。
- 課程列表採用精簡主表，詳細欄位可用每列的 `詳情` 按鈕展開查看。
- 顯示 115-1 候選課表、衝堂矩陣與暑假預習表。
- 匯出 JSON 備份、匯入 JSON 備份、匯出 CSV 給 Excel 或 Google Sheets。
- 一鍵載入 114 學年度檢核表預設資料。

## 資料儲存方式

資料存在瀏覽器的 LocalStorage，key 為：

```text
nckuCreditMapStateV1
```

重新整理頁面後資料會保留。換瀏覽器、清除網站資料、無痕模式結束後，LocalStorage 可能不會保留，因此重要資料請定期匯出 JSON 備份。

如果瀏覽器裡已經有舊版測試資料，請先按 `匯出 JSON` 備份，再按 `載入 114 檢核表預設資料`，即可用正式檢核表預設資料取代目前資料。

更新預設資料後，瀏覽器 LocalStorage 不會自動覆蓋舊資料。若要看到最新抵免紀錄，請在頁面底部按 `載入 114 檢核表預設資料`。
這個按鈕目前也會載入已整理好的 115-1 修課時程資料。

## 決策狀態說明

工具保留兩種狀態：

- `狀態`：用來計算學分是否完成，例如已修、已抵免、已認列、未修、候選、重修。
- `決策狀態`：用來決定現在要不要排這門課，例如 115-1 優先、115-1 備選、115-2 預備、先修未滿、畢業前處理、待問系辦。

已完成學分仍只認列 `已修`、`已抵免`、`已認列`。決策狀態不會直接改變學分計算，避免排課判斷影響畢業進度統計。

## 115-1 排課輔助表

- `115-1 候選課表`：列出下學期可能進正式課表的課，並標示是、備選、否。
- `衝堂矩陣`：固定列出目前已知會撞的課程組合，避免每次重新比對時間。
- `暑假預習表`：列出暑假先讀的課、為什麼要讀、預習目標與每週投入。

## 匯入 / 匯出說明

- `匯出 JSON`：備份課程資料與學分需求設定。
- `匯入 JSON`：載回之前匯出的備份，會取代目前畫面上的資料。
- `匯出 CSV`：匯出課程列表，方便放到 Excel 或 Google Sheets 檢查。

## 114 檢核表規則整理

水利必修需求在工具中設定為 76 學分，包含：

- 專業必修 71 學分。
- 設計必修 4 學分：防洪排水工程設計、水資源工程設計、海洋工程設計、海岸工程設計，任選二科。
- 必選修 1 學分：水利及海洋工程概論。

工具會在「缺口分析」中額外檢查：

- 設計必修是否已完成 4 學分。
- 水利及海洋工程概論是否已有修課紀錄。

英語畢業門檻與體育四學期以 0 學分項目列入課程清單，方便追蹤是否卡畢業。

## 課程決策器 v0.1

這一版在既有課程資料上加入半自動決策層：

- 每門課可設定 `necessityScore` 與 `riskScore`，範圍 1-5，預設 3。
- 每門課可勾選 `planA` / `planB` / `planC`，分別代表穩健復學、正常推進、保守修復三種方案。
- `quadrant` 與 `recommendation` 不存入 LocalStorage，會由 `necessityScore`、`riskScore`、`decisionStatus` 即時計算。
- 課程決策器總表可直接快速勾選 A/B/C，方便反覆調整方案。
- A/B/C 統計會顯示總學分、課程數、高必要高風險課數、平均風險、平衡用課數、先修未滿課數。
- CSV 匯出會包含四象限與建議等級，方便丟到 Excel 或 Google Sheets 檢查。

v0.1 的定位不是全自動排課，而是用可解釋規則輔助判斷哪些課該優先、限量、平衡或暫緩。
