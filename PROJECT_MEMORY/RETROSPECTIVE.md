# Retrospective

## 做得好的地方

- 架構保持簡單，直接開 `index.html` 就能用。
- 沒有導入框架、後端或資料庫，符合本機個人工具定位。
- 核心邏輯有暴露成 `CreditMapLogic`，可以用 Node 測試。
- LocalStorage 讓工具不需要伺服器也能保存資料。
- JSON 匯出匯入提供基本備份與搬移能力。
- CSV 匯出方便轉到 Excel 或 Google Sheets。
- Dashboard、缺口分析、候選課表、衝堂矩陣與暑假預習表能支援實際規劃。

## 需要注意的風險

- LocalStorage 只存在單一瀏覽器與裝置，清除瀏覽器資料會遺失。
- 學分規則、檢核表與課程開課資訊可能變動，不能視為官方保證。
- JSON 備份可能包含敏感個人規劃資料，不能未清理就公開。
- 中文在部分終端或工具中可能出現顯示編碼問題，需要用瀏覽器或 UTF-8 aware 工具確認。
- 若未來資料模型變大，匯入舊 JSON 時需要注意相容性。

## 後續改進方向

- 新增去識別化範例資料，方便公開 demo。
- 新增更清楚的 GitHub Pages 發布說明。
- 新增 JSON schema 或匯入前檢查訊息。
- 補強 UI 文字與 README 的公開版說明。
- 若常更換裝置，可評估手動備份流程，不急著加雲端同步。
- 若加入更多畢業規則，應先把規則拆成可測試函式。

## 長期維護原則

- 先維持本機靜態工具，不過早升級成完整 web app。
- 每次加規則都補測試。
- 每次寫文件都避免寫入個資。
- 優先保存可復用的專案決策，而不是完整聊天內容。
